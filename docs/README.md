# Compiladores 1 — Grupo 01

## Compilador: Mini-C para TypeScript

Projeto da equipe 01 da disciplina de **Compiladores 1** (Prof. Dr. Sergio Antônio Andrade de Freitas — UnB). O objetivo é traduzir um subconjunto da linguagem C (Mini-C) para TypeScript usando as etapas clássicas de um compilador: análise léxica, análise sintática, AST, validações semânticas básicas e geração de código final.

- **Ferramentas fixadas pelo escopo do projeto:** [Flex](https://github.com/westes/flex) + [Bison](https://www.gnu.org/software/bison/)
- **Linguagem-fonte:** Mini-C (subconjunto de C)
- **Linguagem-alvo:** TypeScript
- **Metodologia:** Scrum, com sprints conforme o [Cronograma & Marcos](cronograma.md)
